# Flare One Cashier - Flutter Mobile App (iOS & Android)

تطبيق الموبايل السحابي الموحد لنظام **Flare One (فلير وان)** مبني باستخدام **Flutter & Dart** ليعمل بكفاءة عالية على أجهزة **iPhone (iOS)** وأجهزة **Android** بنفس الكود وقواعد الأمان.

---

## 🚀 المميزات الرئيسية للتطبيق

### 1. نظام الحساب السحابي وصلاحيات الأمان (Cloud Authentication & RLS):
- **تسجيل الدخول**: للمدير، الكاشير، والعميل.
- **إنشاء حساب عميل جديد**: مخصص للعملاء فقط (مع الاسم، الهاتف/البريد، كلمة المرور وتأكيدها، والموافقة على سياسة الخصوصية).
- **أمان حسابات الإدارة**: يُمنع إنشاء حسابات المدراء والكاشير عبر تطبيق الموبايل، وتقتصر على سيستم الكاشير على جهاز الكمبيوتر فقط.
- **حماية البيانات (RLS)**: صلاحيات العميل محصورة في الحجز وتتبع مواعيده الخاصة، ومحجوبة تماماً عن أي فواتير أو بيانات مالية.

### 2. لوحة تحكم المدير ومتابعة الفروع المباشرة (Manager Dashboard):
- **تصفية الفروع لحظياً**: شريط شرائح أفقي للاختيار بين "جميع الفروع" أو فرع محدد لعرض بياناته وفواتيره.
- **مؤشرات الأداء المالي الحي**:
  - إجمالي المبيعات اليومية وعدد الفواتير.
  - رصيد درج النقدية الفعلي بعد خصم المصروفات.
  - بطاقة رصيد بنكي / إنستاباي.
  - بطاقة المحافظ الإلكترونية (فودافون كاش، أورنج، اتصالات).
  - بطاقة المدينون (الآجل وديون العملاء) مع إمكانية الضغط عليها لفتح دليل العملاء.
  - بطاقة مصاريف اليوم التشغيلية.
- **إدارة الحجوزات الواردة**: مراجعة حجوزات الصالون وتأكيدها أو إلغاؤها لحظياً.
- **زر تسجيل خروج آمن**.

### 3. سجل الفواتير والمبيعات السحابي (Invoices Screen):
- استعراض وبحث سريع برقم الفاتورة، اسم العميل، أو الهاتف.
- تصفية المدى الزمني: (اليوم، أسبوع، شهر، الكل، أو مخصص بالتاريخ).
- تصفية الفواتير بحسب الفرع التابعة له.
- تفاصيل كل فاتورة: طريقة السداد، اسم الموظف، المبالغ، والوقت الدقيق.

### 4. سجل العملاء والمديونيات (Customers & Debts):
- بحث فوري في قاعدة عملاء الصالون.
- تمييز مباشر للمدينين الذين عليهم مبالغ آجلة مع تفقيط الرصيد المستحق.

### 5. بوابة حجز وتتبع المواعيد للعملاء (Booking & Appointments):
- إمكانية اختيار الفرع المراد الحجز فيه.
- تعبئة تلقائية لبيانات العميل المسجل (الاسم والموبايل).
- اختيار الخدمة، المصفف المفضل، اليوم والوقت المناسب.
- متابعة واستعلام فوري عن حالة المواعيد.

## 🛠️ دليل تشغيل وبناء التطبيق على الآيفون (iOS / iPhone)

### المتطلبات:
1. جهاز Mac (أو جهاز افتراضي بنظام macOS).
2. برنامج **Xcode** (متاح مجاناً من متجر Mac App Store).
3. تثبيت **Flutter SDK** و **CocoaPods**.

### خطوات التشغيل والتجربة على الآيفون:
1. افتح مجلد المشروع في الـ Terminal:
   ```bash
   cd "pro casher/flutter_app"
   ```
2. تثبيت الحزم والمكتبات:
   ```bash
   flutter pub get
   cd ios && pod install && cd ..
   ```
3. تشغيل التطبيق مباشرة على الآيفون المتصل بالكيبل أو محاكي الآيفون:
   ```bash
   flutter run
   ```

### فتح المشروع في Xcode:
يمكنك فتح ملف مشروع iOS مباشرة في Xcode لضبط شهادات التوقيع (Signing & Capabilities):
```bash
open ios/Runner.xcworkspace
```

### بناء وتصدير حزمة الآيفون الرسمية (IPA / TestFlight):
```bash
flutter build ipa --release
```
ثم رفع الملف الناتج إلى حساب المطور على **Apple Developer** لتوزيعه عبر **TestFlight** أو نشره على **App Store**.

## 📱 تشغيل وبناء الأندرويد (Android)

```bash
cd "pro casher/flutter_app"
flutter run
flutter build apk --release
```
الملف الناتج: `build/app/outputs/flutter-apk/app-release.apk` جاهز للتثبيت المباشر على أي هاتف أندرويد.
