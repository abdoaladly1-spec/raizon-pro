# ⚡ RaiZon Pro v1 - نظام نقاط البيع والكاشير وإدارة المتاجر المتكامل
> منصة سحابية وهجينة احترافية لنقاط البيع (POS)، إدارة المخزون، الحسابات اليومية، سجل الإقفالات، وإشعارات المدير اللحظية بتصميم فاخر وتجربة مستخدم لا مثيل لها.

---

## 🌟 نظرة عامة (Overview)

**رايزون برو (RaiZon Pro)** هو نظام محاسبي ونقاط بيع متطور، مصمم بأحدث تقنيات الويب ليقدم تجربة مستخدم فائقة السرعة، بتصميم فاخر وعصري (Premium UI/UX)، مع دعم كامل للشاشات اللمسية والشاشات العريضة، ودعم ثنائي الاتجاه باللغتين العربية (RTL) والإنجليزية (LTR)، مع التوافق التام مع المظهرين النهاري والليلي (Day / Night Modes) ومجموعة مختارة من **3 ثيمات ملكية فاخرة**.

---

## 🚀 المميزات الجوهرية للنظام (Key Features)

### 1. 🛒 الكاشير ونقاط البيع السريعة (POS & Invoicing)
- **إنشاء الفواتير في أقل من 3 خطوات:** بحث فوري بالاسم، الكود، أو قارئ الباركود التلقائي (Barcode Scanner).
- **شريط الاختصارات السريع الدائم:**
  - `F7`: فتح درج النقدية الكهربائي فوراً للجرد.
  - `F8`: إتمام الفاتورة وتأكيد الدفع السريع.
  - `F9`: تطبيق خصم فوري (نسبة أو مبلغ ثابت).
  - زر بنقرة واحدة لاختيار "عميل نقدي".
- **تعدد وسائل الدفع:** دفع نقدي (كاش)، بطاقات ائتمانية (فيزا / ماستركارد)، محافظ إلكترونية وإنستاباي (InstaPay)، ومبيعات آجلة (ديون).
- **الدفع المركب (Split Payments):** إمكانية تقسيم الفاتورة الواحدة بين الكاش والفيزا والمحفظة.
- **طباعة فورية مزدوجة:** دعم بون حراري 80mm و 58mm، وتصدير فواتير رسمية بحجم A4 مع رمز QR متوافق.
- **إرسال مباشر عبر واتساب (WhatsApp Web):** مشاركة الفاتورة بنقرة زر واحدة مع العميل.
- **حفظ تلقائي للمسودات واسترجاعها:** حماية الفاتورة النشطة من الضياع عند الانتقال بين الصفحات.

### 2. 🕒 الإقفال اليومي الذكي وسجل الإقفالات (Shift Closing & History)
- **الرصيد الافتتاحي التلقائي (Midnight Rollover):** يرحّل النظام المتبقي الفعلي في الدرج من إقفال الأمس تلقائياً بعد الساعة 12:00 منتصف الليل كرصيد افتتاحي لليوم الجديد.
- **مطابقة النقدية الدقيقة (Cash Audit):** معادلة حسابية تفصيلية تحسب المتوقع بالدرج بدقة:
  $$\text{الرصيد الافتتاحي} + \text{المبيعات النقدية} + \text{الإيداعات} - \text{المصروفات النقدية} - \text{المسحوبات} - \text{المرتجعات}$$
- **سجل الإقفال التاريخي الأرشيفي (Closing History):**
  - صفحة مخصصة ومستقلة لأرشفة كل تقفيل يومي عبر التاريخ.
  - فلاتر متطورة: اليوم، أمس، آخر أسبوع، هذا الشهر، أو نطاق تاريخ مخصص.
  - فلاتر حسب الفرع، الكاشير المسؤول، وحالة الجرد (مطابق، عجز، زيادة).
  - تصدير كامل إلى مستندات PDF بحجم A4 مع جداول منسقة وطباعة حرارية مجمعة، وتصدير إكسل (CSV).

### 3. 📦 إدارة المخزون والمشتريات (Inventory & Stock)
- إدارة متكاملة للمنتجات والخدمات مع دعم الباركود وتنبيهات نواقص المخزون (Low Stock Alerts).
- تتبع أسعار التكلفة وسعر البيع لحساب هامش الربح وصافي الأرباح بدقة.
- جرد المخزون، أوامر الشراء، وإدارة الموردين والتصنيفات بدقة مع حالات فارغة (`EmptyState`) توجيهية.

### 4. 💳 إدارة الديون والعملاء ونقاط الولاء (Debts, CRM & Loyalty)
- ملف تعريفي شامل لكل عميل يضم سجل مشترياته ومجموع مدفوعاته.
- جدول ديون العملاء مع إمكانية تحصيل جزئي أو كلي للدين، وتسجيل سند قبض فوري.
- نظام نقاط ولاء ومكافآت تلقائي لكل عملية شراء مع إمكانية استبدال النقاط بخصومات.

### 5. 📊 التحليلات ولوحة التحكم التفاعلية (Dashboard & Analytics)
- التبديل بنقرة زر بين **العرض التنفيذي (4 بطاقات رئيسية)** و **العرض التفصيلي الكامل (10 بطاقات)**:
  - إجمالي الإيرادات، صافي الأرباح، المصروفات، المتوقع بالدرج، الرصيد الافتتاحي، ديون العملاء، عدد الفواتير، متوسط الفاتورة، المرتجعات، وأفضل موظف.
- أرقام واضحة وغير مقتطعة (`dir="ltr"`) لمنع تشوه المبالغ الكبيرة.
- شريط Onboarding توجيهي للمتاجر الجديدة ينقل للخطوات الأولى بنقرة زر.

### 6. 🎨 3 ثيمات ملكية فاخرة (Curated Luxury Themes)
1. **ذهبي فاخر + كحلي داكن (`luxury`)**: الثيم الافتراضي الملكي للنظام.
2. **أزرق محيطي + فضي (`ocean`)**: ثيم الشركات الاحترافي عالي الوضوح.
3. **أسود فحمي + أخضر زمردي (`forest`)**: ثيم أنيق مريح للعين أثناء العمل الطويل.

### 7. 🛡️ خلو تام من نوافذ المتصفح التقليدية (Zero Native Dialogs)
- تم استبدال جميع استدعاءات `confirm` و `alert` بمكون `ConfirmModal` الفاخر ذي الخلفية الزجاجية الداكنة (`backdrop-blur-md`) والتأثيرات الحركية السلسة عبر كافة شاشات وعمليات النظام.

### 8. 🧭 جولة إرشادية تفاعلية (Interactive Tour Guide)
- جولة تفاعلية من 6 خطوات تأخذ المستخدم الجديد في رحلة تعريفية تفصيلية بجميع أركان النظام ومزاياه، مع إمكانية فتحها في أي وقت من الشريط العلوي أو لوحة التحكم أو اختصارات الكيبورد.

## 🛠️ البنية التقنية (Tech Stack)

- **Frontend:** React 18 + TypeScript (Strict Mode) + Vite v6.
- **Styling:** Tailwind CSS + Dynamic CSS Variables + Chrome Glass Effects.
- **State Management & Persistence:** React Context API + LocalStorage + IndexedDB Offline Storage + BroadcastChannel API.
- **Offline & PWA:** Service Worker (`public/sw.js`) + Manifest متوافق مع الحواسيب والأجهزة اللوحية (iPad / Android Tablets).
- **Printing Engine:** ESC/POS Thermal Engine (80mm & 58mm) + High-Resolution Vector Canvas & A4 PDF Generator.
- **Backend Service:** Python 3.12 (FastAPI / Server Scripts) على المنفذ `8087` للنسخ الاحتياطي والإشعارات الفورية.

## 💻 طريقة التشغيل محلياً (Run Locally)

### المتطلبات الأساسية:
- Node.js (الإصدار 18 أو أحدث، يفضل Node 20/22/24)
- Python 3.10+ (اختياري لتشغيل سيرفر الإشعارات)

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تشغيل بيئة التطوير (Development):
```bash
npm run dev
```
سيفتح النظام تلقائياً على الرابط: `http://localhost:4189`

### 3. فحص الأخطاء والأنواع (TypeScript Strict Check):
```bash
npx tsc --noEmit
```

### 4. بناء ملفات الإنتاج (Production Build):
```bash
npm run build
```
