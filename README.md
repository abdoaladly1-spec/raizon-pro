# ⚡ RaiZon Pro v1 - نظام نقاط البيع والكاشير وإدارة المتاجر المتكامل
> منصة سحابية وهجينة احترافية لنقاط البيع (POS)، إدارة المخزون، الحسابات اليومية، سجل الإقفالات، وإشعارات المدير اللحظية.

---

## 🌟 نظرة عامة (Overview)

**رايزون برو (RaiZon Pro)** هو نظام محاسبي ونقاط بيع متطور، مصمم بأحدث تقنيات الويب ليقدم تجربة مستخدم فائقة السرعة، بتصميم فاخر وعصري (Premium UI/UX)، مع دعم كامل للشاشات اللمسية والشاشات العريضة، ودعم ثنائي الاتجاه باللغتين العربية (RTL) والإنجليزية (LTR)، مع التوافق التام مع المظهرين النهاري والليلي (Day / Night Modes) و 6 ثيمات ألوان مخصصة.

---

## 🚀 المميزات الجوهرية للنظام (Key Features)

### 1. 🛒 الكاشير ونقاط البيع السريعة (POS & Invoicing)
- **إنشاء الفواتير في أقل من 3 خطوات:** بحث فوري بالاسم، الكود، أو قارئ الباركود (Barcode Scanner).
- **تعدد وسائل الدفع:** دفع نقدي (كاش)، بطاقات ائتمانية (فيزا / ماستركارد)، محافظ إلكترونية وإنستاباي (InstaPay)، ومبيعات آجلة (ديون).
- **الدفع المركب (Split Payments):** إمكانية تقسيم الفاتورة الواحدة بين الكاش والفيزا والمحفظة.
- **خصومات وضرائب مرنة:** خصم بنسبة مئوية أو مبلغ ثابت مع احتساب دقيق للضريبة.
- **طباعة فورية مزدوجة:** دعم بون حراري 80mm و 58mm، وتصدير فواتير رسمية بحجم A4 مع رمز QR متوافق.
- **إرسال مباشر عبر واتساب (WhatsApp Web):** مشاركة الفاتورة بنقرة زر واحدة مع العميل.

### 2. 🕒 الإقفال اليومي الذكي وسجل الإقفالات (Shift Closing & History)
- **الرصيد الافتتاحي التلقائي (Midnight Rollover):** يرحّل النظام المتبقي الفعلي في الدرج من إقفال الأمس تلقائياً بعد الساعة 12:00 منتصف الليل كرصيد افتتاحي لليوم الجديد.
- **مطابقة النقدية الدقيقة (Cash Audit):** معادلة حسابية تفصيلية تحسب المتوقع بالدرج:
  $$\text{الرصيد الافتتاحي} + \text{المبيعات النقدية} + \text{الإيداعات} - \text{المصروفات النقدية} - \text{المسحوبات} - \text{المرتجعات}$$
- **سجل الإقفال التاريخي الأرشيفي (Closing History):**
  - صفحة مخصصة ومستقلة لأرشفة كل تقفيل يومي عبر التاريخ.
  - فلاتر متطورة: اليوم، أمس، آخر أسبوع، هذا الشهر، أو نطاق تاريخ مخصص.
  - فلاتر حسب الفرع، الكاشير المسؤول، وحالة الجرد (مطابق، عجز، زيادة).
  - تصدير كامل إلى مستندات PDF بحجم A4 مع جداول منسقة وطباعة حرارية مجمعة، وتصدير إكسل (CSV).

### 3. 📦 إدارة المخزون والمشتريات (Inventory & Stock)
- إدارة متكاملة للمنتجات والخدمات مع دعم الباركود وتنبيهات نواقص المخزون (Low Stock Alerts).
- تتبع أسعار التكلفة وسعر البيع لحساب هامش الربح وصافي الأرباح بدقة.
- جرد المخزون، أوامر الشراء، وإدارة الموردين والفئات.

### 4. 💳 إدارة الديون والعملاء (Debts & CRM)
- ملف تعريفي شامل لكل عميل يضم سجل مشترياته ومجموع مدفوعاته.
- جدول ديون العملاء مع إمكانية تحصيل جزئي أو كلي للدين، وتسجيل سند قبض فوري.

### 5. 📊 التحليلات ولوحة التحكم التفاعلية (Dashboard & Analytics)
- 10 بطاقات KPI تفاعلية قابلة للنقر لعرض التفاصيل الكاملة وطباعة تقرير منفصل:
  - إجمالي المبيعات، صافي الأرباح (Accrual Profit)، المصروفات، المتوقع بالدرج، الرصيد الافتتاحي، ديون العملاء، عدد الفواتير، متوسط الفاتورة، المرتجعات، وأفضل موظف.
- رسم بياني تفاعلي (Interactive Bar Chart) يوضح حركة المبيعات وتوزيعها الزمني.
- تصنيف الأصناف الأكثر طلباً والأعلى ربحية.

### 6. ⚙️ الإعدادات المتقدمة وإشعارات المدير (Settings & Notifications)
- **تنبيهات Gmail الفورية:** إرسال إشعارات فورية لبريد المدير عند كل عملية تقفيل أو حركة بيع هامة.
- **نظام النسخ الاحتياطي الذكي:**
  - نسخ احتياطي سحابي تلقائي بالبريد يومياً عند منتصف الليل.
  - نسخ محلي دوري كل 6 ساعات مع الاحتفاظ بأحدث نسختين تلقائياً.
  - نافذة استعادة مخصصة (Custom Modal) تعرض ملخص محتويات ملف النسخة وتطلب التأكيد بأمان.
- **تخصيص الثيمات (Themes):** 6 ألوان ثيم فاخرة (أزرق سماوي، محيطي، غروب برتقالي، زمردي، ليلي بنفسجي، ذهبي فاخر) مع دعم كامل للمظهرين النهاري والليلي.

| :--- | :--- |
| **`F7`** | فتح درج النقدية الكهربائي فوراً للجرد |

| **`Esc`** | إغلاق أي نافذة منبثقة نشطة |

## 🛠️ البنية التقنية (Tech Stack)

- **Frontend:** React 18 + TypeScript + Vite v6.
- **Styling:** Tailwind CSS v4 + Dynamic Theme Variables + Custom Chrome Gradients.
- **State Management & Context:** React Context API + Local Storage + Broadcast Channel API.
- **Printing Engine:** Thermal ESC/POS Engine + Custom Canvas/Browser Print Bridge (A4 & 80mm).
- **Backend Service:** Python 3.12 (FastAPI / Server Scripts) on port `8087` for email notifications & background tasks.

## 💻 طريقة التشغيل محلياً (Run Locally)

### المتطلبات الأساسية:
- Node.js (الإصدار 18 أو أحدث، يفضل Node 20/24)
- Python 3.10+ (اختياري لتشغيل سيرفر الإشعارات)

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تشغيل بيئة التطوير (Development):
```bash
npm run dev
```
سيفتح النظام تلقائياً على الرابط: `http://localhost:4189`

### 3. فحص الأخطاء والأنواع (Type Check):
```bash
npx tsc --noEmit
```

### 4. بناء ملفات الإنتاج (Production Build):
```bash
npm run build
```
