# RaiZon Pro - تطبيق أندرويد (Manager & Customer Portal)

تطبيق أندرويد متكامل مبني باستخدام **Kotlin** و **Jetpack Compose (Material3)**، مرتبط سحابياً بقاعدة بيانات **Supabase** اللحظية الخاصة بنظام الكاشير.

---

## 📱 مميزات التطبيق

### 1. لوحة تحكم المدير اللحظية (Manager Dashboard)
- **مبيعات اليوم الإجمالية**: عداد مالي لحظي مع عدد الفواتير الصادرة اليوم.
- **درج النقدية الفعلي (Cash Drawer)**: مراقبة النقدية السائلة المتوفرة بالدرج لحظة بلحظة بعد خصم المصروفات.
- **رصيد بنكي / انستا (Bank / InstaPay)**: متابعة مدفوعات البطاقات البنكية وInstaPay.
- **المحافظ الإلكترونية**: تتبع مبيعات فودافون كاش والمحافظ.
- **بطاقة المدينون (الآجل)**: تتبع مديونيات وحسابات العملاء.
- **مصاريف اليوم**: مراقبة المصروفات التشغيلية.
- **شريط الفواتير اللحظية**: استعراض الفواتير الصادرة تفصيلياً مع طريقة الدفع والوقت والمبلغ.
- **إدارة الحجوزات الواردة**: قبول وتأكيد أو إلغاء مواعيد حجوزات الزبائن مباشرة من التطبيق.

### 2. بوابة حجز العملاء (Customer Booking Portal)
- اختيار الخدمة (قص كلاسيك، تشذيب لحية، باقة VIP، هيدرافيشل، علاجي...).
- اختيار المصفف المفضل أو "أي مصفف متاح".
- اختيار تاريخ الحجز (اليوم، غداً، الأيام القادمة) والفترة الزمنية المناسبة.
- تسجيل الاسم ورقم الموبايل وتأكيد الحجز فورياً.

### 3. استعلام ومتابعة الحجوزات (My Appointments)
- استعلام سريع للزبون برقم هاتفه للاطلاع على حالة الحجز (قيد المراجعة ⏳ / تم التأكيد ✅ / مكتمل 👍).

## 🛠️ كيفية فتح المشروع في Android Studio وتشغيله

1. افتح برنامج **Android Studio** على جهازك.
2. من القائمة العلوية اضغط على:
   `File` ➡️ `Open`
3. اختر مسار المجلد التالي:
   ```
   D:\abdelrhman\win\pro casher\android_app
   ```
4. سيبدأ Android Studio تلقائياً بعمل مزامنة (Gradle Sync) وتحميل الحزم اللازمة.
5. لتشغيل التطبيق:
   - وصّل هاتفك الأندرويد بكابل USB (مع تفعيل خيار Developer Options و USB Debugging)، أو اختر محاكي (Android Emulator).
   - اضغط على زر **Run** (السهم الأخضر ▶️) في شريط Android Studio العلوي.
6. لاستخراج ملف التثبيت المباشر (**APK**):
   - من القائمة: `Build` ➡️ `Build Bundle(s) / APK(s)` ➡️ `Build APK(s)`.
   - ستجد ملف `app-debug.apk` جاهزاً للتثبيت المباشر على أي هاتف!
